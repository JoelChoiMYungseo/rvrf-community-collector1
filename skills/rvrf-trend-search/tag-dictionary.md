# RVRF 커뮤니티 동향 DB — 태그·이름 사전 초안 (2026-10-21)

목표: 커뮤니티 의견을 한 곳에 같은 기준으로 쌓아서, 사람은 표로 흐름을 보고, Claude는 어떤 질문이든 근거와 함께 바로 찾아 TC·분석 자료로 바꾼다.

DB 칸 구성 (기존 9칸 뒤에 3칸 추가):
`출처 | 날짜 | 구분 | 세부항목 | 요약 | 상세 | 링크 | 관련의견 | 작성자 | 대상 | 반응 | 키워드`

---

## 1. 세부항목 (기존 7개 그대로) — 경계 기준

| 세부항목 | 넣는 것 | 헷갈릴 때 |
|---|---|---|
| 버그 (Bug) | 고장 제보 + (여러 명 제보 / 증거 / 관리자 인정) 중 하나 이상 | 증거가 하나도 없으면 → 문의. 순수 시각 효과는 → UI/UX |
| 문의 | 정보를 묻는 글, 증거 없는 고장 제보 | 화면·메뉴에서 못 찾는 게 핵심이면 → UI/UX |
| UI/UX | 화면·메뉴·안내 때문에 헷갈리거나 못 찾음, 그래픽·시각 이슈 | |
| 개선 사항 (Improvement) | **이미 있는 것**을 바꿔 달라 (수치, 밸런스, 편의, 표시 방식). 관리자의 수정·점검 공지 | "인원 4→6명", "캔디 수급량 올려 달라" |
| 신규 기능 (New Feature) | **없는 시스템·기능**을 새로 만들어 달라 | "보트 운전", "미끼 잠금", "즐겨찾기" |
| 제안 사항 (Suggestions) | **콘텐츠**를 더 넣어 달라 (어종, 맵, DLC, 이벤트, 아이템, 코스튬). 관리자의 신규 콘텐츠·이벤트 공지 | "그리스 DLC", "프로그피시 추가" |
| 감상, 의견 | 감정, 후기, 자랑, 체감, 불만 표현 | 요청이 같이 있으면 행을 나눔 (기존 규칙) |

※ 질문 형태라도 요청이면 요청 쪽(개선/신규/제안). 기존 규칙 유지.
