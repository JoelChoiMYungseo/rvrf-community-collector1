# 체감 QA · 유저 설문 · Fun TC 작성

이 문서들은 **동향 마스터 시트를 먼저 훑고** 쓴다. 기획서·베타 피드백은 보조 근거다.

1. 먼저 `rvrf-trend-search` 스킬로 주제별 동향을 검색한다(건수, 월별 추이, 원문 인용, 링크).
2. 문서의 모든 근거 칸에 **출처 구분**(동향 / 기획서 / 베타)을 적는다. 동향 근거가 없으면 "동향 근거 없음"으로 쓰고 지어내지 않는다.
3. 동향 근거에는 건수와 함께 **집계에 쓴 행 출처 id 목록**(예 `2026-10 / 261020 / 6`)을 남긴다. 그래야 나중에 표본 검증이 된다.
4. 건수는 "관련 글 약 N건"으로 쓴다(키워드 검색이라 노이즈가 섞임). 인용은 상세 원문에서, 링크와 함께.
5. 체크 항목 문장은 작성자가 쓴 것이다. 동향에서 뽑은 문구가 아님을 밝힌다.
6. 기존 산출물 위치: `.claude/notes/`(예 `funtc-draft-*.md`, `RVRF_FunTC_*.xlsx`). 같은 형식을 따른다.

구현·테스트 작업은 이 스킬이 아니라 저장소의 `.claude/INDEX.md`, `/qa`, `/task-start` 등을 따른다(동향 시트를 뒤지지 않는다).
